# 政治人物背景資料庫

**網站：<https://legislator-background.pages.dev>**

投票前，想知道這個人做過什麼、有沒有官司、錢從哪裡來？這個網站把散落在各政府機關與新聞裡的公開資料整理在一起，每一筆都附上出處，讓你自己點進去看原文、自己判斷。

> **本站非官方網站。** 我們只整理公開資料並標註出處，不替任何人打分數、不做價值判斷。
> 尚未定讞的案件，當事人依法受無罪推定保障。

## 可以查到什麼

收錄第 11 屆立法委員、2022 年當選的縣市首長與縣市議員，以及 2026 年縣市長候選人，共約 1,100 人。每個人的個人頁有：

- **經歷**：公職與相關職務。
- **司法判決**：只收有罪判決，而且查到最新審級；還在上訴中的會標示「未定讞」。
- **爭議**：媒體報導過的公共事件，包含已經不起訴或判無罪的（會標示清楚）。
- **財產申報**：監察院公報上的申報資料。
- **政治獻金**：歷次選舉的收支與大額捐贈者。
- **人物關係**：家族、派系、師承等經查證的關係，以關係圖呈現。

另外還有：

- **[2026 九合一選舉](https://legislator-background.pages.dev/elections)**：各縣市長與縣市議員候選人名單、六都對決一覽、選務時程，可以從地圖逐層點進縣市、鄉鎮與選區。
- **[政治獻金查詢](https://legislator-background.pages.dev/donors)**：用公司名稱查它捐給了哪些政治人物。
- **[人物關係圖](https://legislator-background.pages.dev/graph)**：全站人物之間的關係網。

## 資料從哪裡來、怎麼查證

| 資料 | 來源 | 怎麼處理 |
|---|---|---|
| 司法判決 | 司法院裁判書 | 每筆人工確認是本人（看判決書載明的職務、經歷），並查到最新審級才上架；同名同姓、無法確認者一律不收 |
| 爭議 | 主流媒體、法院、監察院等公開資料 | 2026 縣市長候選人的爭議經過兩輪查證與獨立核對才上架；其他人物的爭議整理自維基百科所附的媒體報導，只保留有原始新聞來源者 |
| 財產申報 | 監察院公職人員財產申報公報 | 程式解析公報 |
| 政治獻金 | 監察院政治獻金公開查閱平臺 | 程式比對到人；候選人的專戶逐筆人工確認 |
| 候選人名單 | 中央選舉委員會候選人名冊 | 依選務進度（登記 → 審定 → 號次 → 公告）更新 |
| 選舉結果、行政區界線 | 中選會投開票資料、內政部國土測繪中心 | — |

詳細的收錄範圍與方法請見網站的[關於頁](https://legislator-background.pages.dev/about)。

## 發現錯誤？

如果資料有誤、狀態需要更新，或您是當事人希望更正或移除，請到 **[Issues](https://github.com/weryk153/legislator-background/issues)** 回報，並附上對應頁面與佐證，我們查核後會盡快處理。依《個人資料保護法》，當事人得請求查詢、更正或刪除本站所載的個人資料。
