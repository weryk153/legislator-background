# 全站報章風改版（EVA 點綴）設計 spec

**目標**：整站改成報紙版面的調性，以《新世紀福音戰士》標題卡的字形與構圖做點綴。報紙為主、EVA 點綴；整體要**簡潔**。資料頁的中立原則（候選人同字級、同版型、依名冊順序、筆數同色只列數字）與可讀性不得因改版受損。

**參考**：Shopping Design〈EVA 明朝體〉（https://www.shoppingdesign.com.tw/post/view/4428 ）：Matisse-EB 特粗明朝、黑底白字、橫豎直角排列、字級落差大、標題卡。

**定案 mock**（`.superpowers/brainstorm/33035-1791351644/content/`，未進版控）：

| 檔案 | 內容 |
|---|---|
| `full-home-v3.html` | 首頁整頁（精簡版＋線性時程） |
| `full-county-v3.html` | 縣市選舉頁整頁（澎湖縣；縣長候選人 D1，背景色以純白為準） |

## 1. 已定的決定

| 項目 | 決定 | 否決的選項與理由 |
|---|---|---|
| 力道 | 報紙為主、EVA 點綴 | EVA 為主（大面積黑底傷可讀性與中立感）；只改首頁 |
| 黑色面積 | 黑塊只包住字（標題卡、章節標） | 整片黑底標題卡、黑色報頭——使用者明確表示黑色太多 |
| 簡潔度 | 精簡版（mock v3） | 日期列、宗旨列、頭版三欄、英文副標、第弐話編號、表格直欄線等都拿掉——使用者表示不夠簡潔 |
| 報頭 | 全名「政治人物背景資料庫」 | 「政治人物資料庫」（失去「背景」辨識度、等同換品牌）；「○○報」短名（換品牌） |
| 標題卡內容 | 放各頁主題，不重複站名 | 「看見政治人物的背景」——與報頭重複 |
| 時程 | 沿用現行線性時程軸 | 條列式時程 |
| 縣長候選人 | D1 兩欄人物欄 | D2 名冊表 |
| 背景色 | 純白 `#fff`，墨色純黑 `#000` | 新聞紙 `#f4f1e8`（報紙感強但福音感弱）；現行 `#faf9f6`；舊報紙 `#ece6d6`（長文發悶、灰字對比差） |
| 字體 | 沿用 Noto Serif TC 900，水平壓扁 | Matisse-EB 為商用字型，不能當網頁字型載入 |

## 2. 視覺系統

### 2.1 色票（`src/styles/tokens.css`）

淺色：

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#fff` | 頁面底色 |
| `--fg` | `#000` | 文字、粗線、黑塊 |
| `--muted` | `#4d4d4d` | 次要文字（白底對比約 8.5:1） |
| `--faint` | `#767676` | 輔助小字（白底對比約 4.5:1，AA 下限） |
| `--line` | 中性灰髮絲線 | 列分隔 |
| `--line-strong` | `#000` | 欄線、表頭底線 |
| `--accent` | 朱紅（沿用色相） | 只用在：標題卡直排小字、時程「今天」、「已解職」 |

- 政黨色、地圖狀態色不變。
- 深色模式保留：底近黑、字近白；**黑塊在深色模式反轉為白底黑字**（否則與背景融成一片）。

### 2.2 壓扁特粗明朝 `.sq`

Noto Serif TC 900 以 `transform: scaleX(var(--k))` 水平壓扁。`transform` 不改版面寬度，壓扁後右側會留下空白（黑卡右邊空一截），所以用負 margin 收回：

```css
.sq {
  font-family: var(--serif); font-weight: 900; display: inline-block;
  line-height: .95; letter-spacing: -.03em;
  transform-origin: left bottom; transform: scaleX(var(--k, .7));
  margin-right: calc((var(--k, .7) - 1) * var(--n) * .97em);
}
```

- `--n` 為字數（全形字寬 1em，含 −.03em 字距故乘 .97）。元件以字串長度自動帶入，不手填。
- 壓扁比例：報頭 .7、標題卡大字 .62、章節標 .7、人名 .78～.8。
- 只用在全形字為主的短字串（標題、人名、章節名）；內文、數字表格不用。

### 2.3 報頭與導覽（`src/layouts/Base.astro`）

- 一列：左「政治人物背景資料庫」（`.sq`，桌機約 52px）、右日期＋資料更新日＋深淺切換鈕。
- 下接 4px 粗線、一列導覽（總覽／九合一選舉／政治獻金／關係圖／關於；目前頁加粗）、導覽下一道細線。
- 首頁的 `<h1>` 是報頭站名；其他頁報頭是連回首頁的連結，`<h1>` 在標題卡。
- 窄螢幕：報頭字級縮小（以不超出視窗為準），導覽可換行。

### 2.4 黑標題卡（新元件 `src/components/TitleCard.astro`）

- 黑底白字，只包住內容（`inline-grid`），不撐滿寬。
- 構圖：左側直排朱紅小字；右側兩行壓扁大字，第一行約為第二行的 2～2.5 倍。
- props：`vertical`（直排小字）、`lines: [大, 小]`、`href?`（頭條可點）、`as: 'h1' | 'h2' | 'div'`。
- **SEO 既有 `<h1>` 文字不變**（縣市頁、個人頁的標題字串近期才為搜尋調過）：標題卡的視覺字串與語意標題不同時，語意標題以 `sr-only` 放在 `<h1>`，卡片本身 `aria-hidden`。
- 各頁內容：

| 頁面 | 直排 | 大字 | 小字 | 語意 `<h1>` |
|---|---|---|---|---|
| 首頁（頭條，`h2`、連到 /elections） | 第壱話 | 九合一 | 候選人背景總整理 | （h1 為報頭） |
| /elections | 二〇二六 | 九合一 | 選舉 | 沿用 ElectionPanel 的 h1 文字 |
| 縣市頁 | 二〇二六 | 〈縣市〉 | 〈縣/市〉長・議員選舉 | `countyPageHeading()` 原字串 |
| 個人頁 | 黨籍 | 〈姓名〉 | 現有 `roleText`（如「立法委員・臺中市第1選舉區」「2026 澎湖縣長參選人」） | 〈姓名〉 |
| 政治獻金 | 監察院資料 | 政治獻金 | 查詢 | 政治獻金查詢 |
| 關係圖 | 公開資料 | 人物 | 關係圖 | 人物關係圖 |
| 關於 | 說明 | 關於 | 本站 | 關於本站 |
| 2022 選舉 | 二〇二二 | 九合一 | 選舉結果 | 沿用 ElectionPanel 的 h1 文字 |
| 404 | 404 | 找不到 | 這個頁面 | 找不到這個頁面 |

### 2.5 章節標

- 取代現行 `h2` 樣式：黑塊（`.sq` 字約 26px）＋右側延伸到欄寬的 4px 粗線。
- 用全域 class（或 `SectionHead.astro`），語意仍是 `<h2>`。

### 2.6 頭像

- 圓形一律改直式方框（約 4:5），`object-position: center top`。
- 無照片：同尺寸方框、淺灰底、姓氏一字（`.sq` 不壓扁、灰字）。
- 照片維持彩色。

### 2.7 頁尾

- 一道 4px 粗線，下面免責聲明、資料來源、連結（關於與免責／更正／回報問題）。與 `.wrap` 同寬。

### 2.8 其他

- 圓角歸零（輸入框、下拉選單、按鈕、標籤）。
- 輸入框與下拉選單：1px 黑框、透明底。
- 狀態標籤（爭議的「已起訴」等）：直角黑框小字，不填色。

- `.sq` 收回寬度：標題卡、章節黑塊右側無多餘空白；手機寬度不溢出。
- SEO：各頁 `<title>`、`<h1>` 文字與改版前一致（建置後比對 dist）。

## 6. 進行方式
