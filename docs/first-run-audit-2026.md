# 2026 首次參選逐人查核

查核日：2026-10-14。範圍：中選會 2026-09-07 首長與議員登記名冊的 22 縣市、1,583 人；此為登記階段，非最終審定名單。

已完成本輪逐人資料查核。42 人有明確首次參選證據，1,154 人已確認曾參選公職，387 人完成檢索但證據不足。42 人是目前可確認名單，不能視為全國首次參選者的完整人數。

## 定義與證據

首次參選是第一次參選任何公職，包含村里長、鄉鎮市民代表與不分區立委。副市長、局處長等任命職務本身不構成參選紀錄；初次選議員、政治新人、非現任與查無歷史命中都不能單獨作為確認依據。

先核對已具來源的本人履歷與中選會歷屆候選人資料，再對尚未判定者逐人檢索，追查具名報導、本人與政黨官方介紹及選舉公報。歷史資料涵蓋1994年至2024年多次選舉共93,548筆候選紀錄，但未涵蓋所有年代、補選或姓名變更，未命中不表示從未參選。姓名相同但身分無法串聯時保留未確認；不將親屬或其他縣市同名人物的紀錄套入。

所有人的狀態、證據與查核日期保存在 [逐人底稿](../scraper/candidate-first-run-audit.json)。未確認者另留搜尋與不足原因；部分搜尋來源僅為線索，不代表已證實該候選人的經歷。網站只對 first-run 顯示標記，其他兩類不顯示，避免把證據不足解讀為否定。

## 維護方式

新增證據時先更新逐人底稿，執行 `pnpm candidates:first-run-audit --write` 驗證後產生確認名單，再執行 `pnpm build:candidates --stage registration`。測試會核對全國名冊完整覆蓋、唯一人物身分及發布標記與確認名單完全一致。未確認者應在取得明確報導、候選人聲明或可串聯身分的歷史資料後更新；沒有證據不自動改判。

## 驗證

844 項測試通過，網站成功建置 1,924 頁。逐一檢查 1,583 個候選人個人頁，42 個首次參選標記均含 2026 年度並連到該人的查證來源，其餘 1,541 人無此標記。候選人姓名、名冊與人物連結未變。本次資料、建置與頁面驗證均於本機完成。
