# New route: /graph/connect/
A text-first interactive page for asking 這兩個人，有什麼關係？ Reuse the existing Base shell and tokens. Two searchable person fields with distinct identity descriptions; find one shortest path from the existing graph. Controls 查詢關係, 交換兩人, 換一組看看. Clear empty and disconnected states.

Represent the path as an ordered sequence with neutral connector rules, not causal arrows. Large accent hop count and equally styled node cards; organizations can be intermediates. Below the short route, show numbered original evidence notes with source links for each edge. Same-name people are distinct choices. Distances are only number of recorded links, never strength or influence. Source-backed path is not an inference of direct relation between endpoints.

Use this exact existing-data sample, do not invent any political facts:
林佳龍 — 正常國家促進會（正國會） — 卓冠廷. Two recorded links both labelled 同派系. First note: 維基百科正常國家促進會條目載，現以掌門人外交部長林佳龍與前民進黨秘書長林右昌為核心。 Second note: 維基百科正常國家促進會條目列卓冠廷為派系重要成員。 Both source links are https://zh.wikipedia.org/wiki/正常國家促進會 . The tool describes the data record; titles are historical descriptions, not a current appointment claim.

White/black editorial layout, vermilion accents, large compressed serif headings matching TitleCard, readable small sans-serif evidence notes. No photos required, no circles with initials. On mobile show a vertical path and stacked form, no sideways scrolling. Footer note: 路徑僅表示本站資料中的連接，不代表兩人有直接往來；找不到路徑也不表示沒有關係。
